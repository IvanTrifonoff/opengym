# Демо-сценарий: лояльность, влияющая на вовлечённость

Материал для презентации продукта (владельцам залов / тренерам). Показывает,
как программа лояльности начисляет баллы за реальные действия спортсменов и
как это выглядит в админке/приложении.

## Персонажи

| Спортсмен | Сценарий | Суть для презентации |
|---|---|---|
| **Artem** | Активный лоялист | Регулярно ходит (10 визитов + 6 тренировок за 3 недели), заработал **275 баллов**, погасил **«Фирменную футболку»** (200) — полный цикл: действие → баллы → награда. Привёл друга по рефералке (+50). |
| **Maxim** | Новичок, «разогретый» | Пришёл по реферальной ссылке Artem (+50 приветственный бонус), сделал первые 3 визита и 3 тренировки → **125 баллов**, копит на награду. Видит прогресс сразу. |
| **Testuser1** | Угасший | 3 визита за месяц, без тренировок и стриков → **30 баллов**. Наглядный контраст: кто не вовлечён — баллы не растут. |

**Тренер Андрей** — ведёт всех трёх (видит их в своём ростере и в «Удержании»).

## Механика (правила и награды)

| Правило | Событие | Баллы |
|---|---|---|
| Визит в зал | `visit` | +10 |
| Завершённая тренировка | `workout_completed` | +15 |
| Стрик 3+ тренировки | `streak` | +25 |
| Реферальная программа | `referral` | +50 |

| Награда | Стоимость | Выдача |
|---|---|---|
| Скидка 10% на абонемент | 150 | код автоматически (`auto_code`) |
| Фирменная футболка | 200 | вручную тренером (`staff`) |
| +1 персональная тренировка | 300 | вручную тренером (`staff`) |

## Как воспроизвести (сидер)

Скрипт `scripts/seed-loyalty-demo.sh` создаёт спортсменов (Maxim), правила,
награды и шлёт события через честный API-вебхук `/api/integrations/loyalty/events`
(с `x-opengym-webhook-secret`), так что начисление и уведомления идут как в проде.

```bash
# на сервере с развёрнутым стеком (gym.trfnv.ru)
bash scripts/seed-loyalty-demo.sh
```

Идемпотентность: повторный запуск не дублирует баллы (события имеют
уникальные id, `ON CONFLICT DO NOTHING`).

## Где смотреть в UI

- **Спортсмен (Artem/Maxim):** вкладка «Лояльность»/«Награды» — кошелёк, история
  начислений, каталог наград, редемпшн.
- **Тренер Андрей (`/trainer`):** «Мои спортсмены» — 3 подопечных; «Удержание» —
  кто активен, кто в зоне риска.
- **Владелец (`/admin`):** «Лояльность» — правила, награды, редемпшны (виден
  редемпшн футболки Artem в статусе pending — выдаёт тренер); «Аналитика» — динамика.
- **Уведомления:** при начислении баллов спортсмен получает «+N баллов — <правило>»
  в центре уведомлений.

## Чего показывать не нужно

- Тестовые события созданы с уникальными id (`art-*`, `mx-*`, `tu-*`) — они
  не конфликтуют с боевыми данными. При необходимости очистка:
  удалить события `art-*`/`mx-*`/`tu-*` и ledger по ним, вернуть balance.
